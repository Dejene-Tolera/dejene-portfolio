DEJENE TOLERA PORTFOLIO

1. Open this folder in VS Code.
2. Edit index.html for your name, biography, projects and links.
3. Edit style.css for colors, fonts and layout.
4. Edit script.js for interactive behavior.
5. Put your profile photo at images/profile.jpg.
6. Put your CV at assets/Dejene_Tolera_CV.pdf.
7. Replace YOUR_USERNAME and YOUR_EMAIL@example.com in index.html.
8. Open index.html in a browser to test it.
9. Upload all files to your GitHub Pages repository.
